ShortReelz Automation Privacy policy

Privacy policy

Effective November 15, 2026

ShortReelz Automation is operated by the owner of the ShortReelz channel and uses YouTube API Services. See the Google Privacy Policy for information on how Google handles data.

What the app accesses

The channel operator authorizes the app through Google. The app uses that authorization to send videos, thumbnails, and publishing details to YouTube. It reads the returned video ID, visibility, and processing status to confirm uploads and time thumbnail updates.

How the app stores and shares data

The authorization file is created on the operator’s computer. The operator stores a copy as an encrypted GitHub Actions repository secret so scheduled jobs can sign in to the YouTube API. The private repository’s workflow logs can contain video IDs, Studio links, and upload status. Rendered videos and covers can be retained as GitHub Actions artifacts. YouTube receives the files and metadata needed to publish them. Video content and publishing details appear on YouTube according to the chosen visibility.

The app does not sell account data or use it for advertising. These informational pages do not include forms, analytics scripts, or tracking cookies.

Revoke access or delete stored data

The operator can revoke the app’s access in Google Account connections, delete the local authorization file and GitHub Actions secret, and remove workflow logs and artifacts from GitHub. Videos already uploaded can be managed in YouTube Studio.

Contact

For privacy questions or deletion requests, contact the operator through the project’s GitHub issue page. The issue page is public, so keep account credentials and other sensitive information out of your message.
