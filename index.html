ShortReelz Automation

A personal publishing tool for the ShortReelz YouTube channel.

The tool turns scripts into short vertical videos with narration, photos, and captions. It uses YouTube API Services to upload videos on the owner’s schedule, check when each video finishes processing, and apply a custom thumbnail.

Access to the uploader is limited to the channel operator. This site explains the app and how it handles account data.
